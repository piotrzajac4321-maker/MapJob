8 gotowych kreacji 1080×1080 do kampanii Facebook/Instagram.

Jak użyć tego pliku:
1. Otwórz w Chrome (F11 dla full screen, wyłącz inne karty)
2. Zainstaluj rozszerzenie "Awesome Screenshot" albo użyj Windows Snipping Tool (Shift+Win+S)
3. Zrób zrzut każdej kreacji dokładnie 1080×1080 px (framka jest tej dokładnie wielkości — widzisz ją w skali 55%/85%)
4. Najlepiej: prawym przyciskiem na kreacji → Inspect → Right-click na elemencie .fb-frame → Capture node screenshot → Chrome zapisze PNG 1080×1080
5. Upload do Facebook Ads Manager

Alternatywa — eksport do PNG przez DevTools: Otwórz DevTools (F12) → Run command (Ctrl+Shift+P) → wpisz "Capture node screenshot" → wybierz kreację → zapisze się PNG w pełnej rozdzielczości 1080×1080.
