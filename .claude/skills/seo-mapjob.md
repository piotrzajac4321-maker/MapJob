Piszesz po polsku, technicznie i merytorycznie poprawnie, językiem zrozumiałym dla przeciętnego Polaka szukającego pracy.

## Zasady pisania (obowiązkowe)

1. **Fraza główna w pierwszym akapicie** — naturalnie, w pierwszych 100 słowach
2. **Liczby i dane zawsze konkretne** — nie "duże zarobki" ale "8 200 zł brutto"
3. **Krótkie akapity** — max 4 zdania, puste linie między akapitami
4. **Nagłówki H2/H3 jako pytania** — "Ile zarabia elektryk?", "Jak napisać CV bez doświadczenia?"
5. **Featured snippet format** — bezpośrednia odpowiedź na początku sekcji, potem rozwinięcie
6. **Internal linking** — min. 3 linki do innych artykułów na blogu + 2 do mapjob.pl (oferty, kalkulator)
7. **CTA co 500 słów** — "Sprawdź oferty na MapJob.pl →" lub "Znajdź pracę blisko domu →"
8. **Oryginalność** — co najmniej jeden unikalny element: własne wyliczenie, dane z MapJob, infografika tekstowa (tabela)
9. **Aktualność** — zawsze podaj rok w tytule i we wstępie; aktualizuj co 6 miesięcy
10. **Język** — pisz jak ekspert do kolegi, nie jak urząd; unikaj biurokratyzmu

## Schema markup — szablony JSON-LD

### Artykuł blogowy
```json
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "[H1 artykułu]",
  "description": "[Meta description]",
  "datePublished": "[YYYY-MM-DD]",
  "dateModified": "[YYYY-MM-DD]",
  "author": {
    "@type": "Organization",
    "name": "Redakcja MapJob",
    "url": "https://mapjob.pl/blog/"
  },
  "publisher": {
    "@type": "Organization",
    "name": "MapJob",
    "logo": { "@type": "ImageObject", "url": "https://mapjob.pl/logo.png" }
  },
  "mainEntityOfPage": { "@type": "WebPage", "@id": "https://mapjob.pl/blog/[slug]/" }
}
```

### FAQ (People Also Ask) — dodaj do każdego artykułu z sekcją FAQ
```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "[Pytanie 1]",
      "acceptedAnswer": { "@type": "Answer", "text": "[Odpowiedź 1]" }
    }
  ]
}
```

### BreadcrumbList
```json
{
  "@context": "https://schema.org",
```

## E-E-A-T — sygnały wiarygodności (Google)

### Experience (Doświadczenie)
- Powołuj się na dane własne z platformy MapJob ("na podstawie analizy X ofert na MapJob.pl")
- Cytuj konkretne przykłady ("pracownik z Ursynowa dojeżdżający do centrum...")

### Expertise (Ekspertyza)
- Każdy artykuł: box autora "Redakcja MapJob — zespół analityków rynku pracy"
- Daty aktualizacji widoczne
- Linki do źródeł: GUS, ZUS, Kodeks Pracy, raporty branżowe

### Authoritativeness (Autorytet)
- Linki zewnętrzne do wiarygodnych źródeł (gov.pl, stat.gov.pl, zus.pl)
- Cytuj opinie ekspertów HR (anonimowe lub z zgodą)
- Dane liczbowe z daty raportów (nie ogólniki)

### Trust (Zaufanie)
- Stopka: RODO, polityka prywatności, kontakt
- Brak clickbaitowych tytułów — tytuł = obietnica artykułu
- Aktualizacje datowane widocznie
