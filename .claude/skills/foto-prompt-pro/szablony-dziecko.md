# Szablony — starsze dziecko, sitter, cake smash, rodzinne

Rozszerzenie oferty poza newborn. Te same 12 warstw, inne pozy/bezpieczeństwo i inny obiektyw (więcej ruchu → 50mm). Tryb A: identity-lock jak w `anatomia-promptu.md` (dla starszego dziecka dodatkowo: „preserve the child's eye color and smile").

## Sitter (6–9 mies., siedzi samodzielnie)

`Sitting upright unassisted, chubby cheeks, bright curious expression, looking toward camera. Outfit: cream waffle-knit romper. Background: neutral studio backdrop, soft beanbag, gentle depth. Lighting: large softbox key light, soft catchlights in both eyes, 5000K. 50mm f/2.0, eye-level. Color: warm neutral. Mood: cheerful, alert.`

## Older baby / toddler (stoi/chodzi)

`Standing toddler holding a soft wooden toy, playful natural posture, candid genuine smile. Outfit: linen overalls. Background: clean minimal studio or soft pastel set with depth. Lighting: soft directional key, airy, 5300K. 50mm f/2.2, slight low angle for a confident look. Mood: playful, lively.`

## Cake smash (1. urodziny)

`One-year-old sitting behind a pastel birthday cake, hands in the frosting, joyful messy candid moment, genuine laughter. Outfit: themed romper with a tiny crown or bow. Background: balloon garland and bunting, soft bokeh party set with clear depth. Lighting: bright high-key party light, colorful soft fill, 5400K. 35mm f/2.5 to capture scene + child. Color: vibrant pastel celebration palette. Mood: fun, energetic, candid.`

## Rodzinne (rodzic + dziecko)

`A parent gently cradling the baby, tender connected moment, both faces visible and in focus. Tryb A: preserve BOTH faces and identities from the reference photos with 100% fidelity. Outfit: coordinated neutral knit/linen tones. Background: warm cream studio or cozy home set with soft depth. Lighting: large soft window-style key, wraparound soft fill, catchlights in all eyes, 4800K. 35mm f/2.8 to keep both sharp. Color: warm neutral, true skin tones. Mood: intimate, loving, fine-art.`

> **Uwaga wielu twarzy:** przy 2+ osobach dokładnie wskaż, które twarze zachować i że WSZYSTKIE mają być ostre (większa przysłona f/2.8–f/4, nie f/1.8). Wskaż relację (parent cradling baby), by model nie pomylił skali/proporcji.

## Bezpieczeństwo i naturalność wg etapu

- **Newborn**: tylko pozy wsparte / composite-safe (patrz `realizm-checklist.md`).
- **Sitter**: zawsze „sitting unassisted” lub wsparcie poza kadrem; nie wymuszaj nienaturalnych skłonów.
- **Toddler/cake smash**: candid > sztywne pozowanie — proś o „genuine, candid expression”, nie „posed smile”.
- **Rodzinne**: realistyczne proporcje dorosły–dziecko, naturalny dotyk/uchwyt.
