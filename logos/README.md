# Folder na pliki logo

Wrzuć tutaj plik PNG/SVG/WEBP logo firmy, używając nazwy w formacie:
`[nazwa-firmy].[ext]`

Przykład: `berker-dominis.png`

Po wrzuceniu pliku Claude automatycznie:
1. Wstawi logo do `index.html` (sekcja ZAUFALI NAM)
2. Wstawi kartę do `zaufali-nam/index.html`
3. Commituje i pushuje na `vercel-deploy`
