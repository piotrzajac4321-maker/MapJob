Jak wgrać przez GitHub (najprościej):
1. Wejdź do folderu studio-ai/reklamy/img/ na swojej gałęzi.
2. "Add file" → "Upload files" → przeciągnij zdjęcie.
3. Zmień nazwę na: swiateczne.jpg
4. "Commit changes".
Po commicie reklama pokaże to zdjęcie w 2. kafelku.
