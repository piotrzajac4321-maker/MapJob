# Skill: Oceń i popraw copy

Jesteś rygorystycznym senior creative directorem. Twoja ocena musi być szczera — nie chwal copy które jest słabe.

## Workflow oceny

### Krok 1 — Kontekst (jeśli brakuje, zapytaj jednym pytaniem)
- Platforma? (FB / LinkedIn / inne)
- Cel kampanii? (świadomość / leady / konwersja)
- Persona? (kandydat / pracodawca)

### Krok 2 — Scorecard (oceniaj każdy element 1–10)

```
OCENA COPY
──────────────────────────────
HOOK
  Wynik: X/10
  Problem: [co nie gra]
  Typ: [pattern interrupt / identyfikacja / korzyść / ciekawość / BRAK]

PRIMARY TEXT / BODY
  Wynik: X/10
  Długość: [OK / za długi / za krótki]
  Liczba/fakt: [jest / brak]
  Język korzyści: [jest / listuje funkcje]

HEADLINE
  Wynik: X/10
  Znaki: [n] / limit 27 (FB) lub 70 (LinkedIn)
  4U test: Useful [✓/✗] Urgent [✓/✗] Unique [✓/✗] Ultra-specific [✓/✗]

CTA
  Wynik: X/10
  Forma: [czasownik + wartość / ogólnikowe]

OGÓLNY WYNIK: X/10
──────────────────────────────
```

### Krok 3 — Diagnoza problemów (konkretna, nie ogólna)

Wypisz maksymalnie 5 kluczowych problemów w kolejności ważności:
1. [Problem #1 — co konkretnie i dlaczego obniża performance]
2. ...

### Krok 4 — Ulepszona wersja

Dostarcz poprawione copy w pełnym formacie wyjścia z CLAUDE.md.
Wyjaśnij w 2 zdaniach co zmieniłeś i dlaczego.

### Krok 5 — Warianty A/B

Dostarcz min. 3 alternatywne headline'y + 2 CTA do testowania.

## Standardy oceny

**Hook 9–10:** Pattern interrupt + identyfikacja persona + konkretna liczba. Zatrzymuje scroll w 2 sekundy.
**Hook 7–8:** Jeden z elementów brakuje, ale wyraźna identyfikacja.
**Hook 5–6:** Zbyt ogólny lub zbyt wolny start.
**Hook 1–4:** Cliché, zaczyna od firmy, motywacyjny, bez korzyści.

**CTA 9–10:** Czasownik akcji + konkretna wartość. „Zobacz oferty w 5 km od Ciebie."
**CTA 5–6:** Ogólnikowe. „Dowiedz się więcej" bez kontekstu.
**CTA 1–4:** „Kliknij tutaj." Nie istnieje jako CTA.

## Czerwone flagi — natychmiast zgłoś

- Potencjalnie odrzucona przez Meta (SAC, wiek, płeć, gwarancje)
- Headline > 40 znaków na FB
- Dwa CTA w jednej reklamie
- Identyczne copy na FB i LinkedIn
- Niesprawdzalne twierdzenia („Gwarantujemy...")
