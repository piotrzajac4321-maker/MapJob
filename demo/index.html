Setup bazy — instrukcja

Jak uruchomić prawdziwą aplikację (nie tylko demo).

  1. Stwórz projekt Supabase (region Frankfurt).
  2. Skopiuj init.sql z repo (plik obok tego HTML, 36 KB).
  3. Wklej do Supabase → SQL Editor → New query → Run.
  4. Sklonuj repo, pnpm install, uzupełnij .env.local kluczami z Supabase.
  5. pnpm --filter @mapjob/web dev → localhost:3000.

Ten HTML to klikalny prototyp UI bez backendu. Po setupie powyżej dostajesz pełną apkę z auth, bazą, generatorem AI, rozszerzeniem Chrome.
