Setup bazy — instalacja schematu

Jednorazowe. Wykonaj poniższy SQL w Supabase SQL Editor, żeby aktywować pełną aplikację.

  1. Otwórz Supabase SQL Editor →
  2. Kliknij "Copy SQL" poniżej i wklej w edytorze (Ctrl+V).
  3. Kliknij "Run" w prawym dolnym rogu. Skrypt utworzy 11 tabel, 6 widoków, triggery, RLS, RPC.
  4. Wróć tu i odśwież stronę — banner zmieni kolor na zielony.
